# Ekom-Nkam — site vitrine

Prototype éditorial du village d’**Ekom-Nkam** (commune de Baré-Bakem, Moungo, Littoral, Cameroun), centré sur les chutes du Nkam.

## Documentation

Voir le dossier [`docs/`](docs/) : méthode documentaire, sources S1–S10, fiches par section et collecte de terrain.

## Développement

```bash
npm run dev    # http://127.0.0.1:4173
npm run build  # génère dist/
```

Prototype indépendant : aucun mandat de la mairie ni du MINTOUL n’est revendiqué.
